# PoE Bingo — INSOMNIA

A simple, single-file **bingo card generator** for the *Path of Exile 1: Curse of the Allflame* league.

## Features

- Title: *PoE 1: Curse of the Allflame*
- Player nickname field
- Editable **5×5 bingo grid**
- Automatic text wrapping and auto font-size, so every cell always fits
- **Export the card as a PNG** image (downloads to disk)
- League-themed styling — underwater teal background with intense green borders/text
- Works fully **offline**: a single `index.html`, no dependencies, no build step

## Usage

Open the live page, type your nick, fill the 25 cells, then click **„Zapisz jako grafikę (PNG)"** to download your bingo card.

Or run locally: download `index.html` and open it in any modern browser.
